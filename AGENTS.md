# KKdesign-kit contributor contract

This repository contains Stage-A foundations and the B1 installable skill preview.
Keep command availability honest: packaging works; B2/B3 design operations remain planned.
Keep the shared contracts independent of Figma, Git hosting, a particular DS, and local memory tools.
Use Python 3.9+ and `requirements.txt`. Run `python -m unittest discover -s tests -v` after core changes.
Keep all committed examples synthetic. Do not add customer registries, private Figma IDs, product evidence, credentials, local machine paths, or copied upstream binaries.
Do not infer native behavior or human approval from a schema check. Preserve historical evidence payloads during migrations.
Codex and Claude Code consume the same project data. Harness-specific discovery and installation live in the B1 installer; hooks remain separate and opt-in.
